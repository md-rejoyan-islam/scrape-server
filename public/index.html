API Endpoints

Everything the UI does is available over a simple REST API.

POST
/api/scrape Synchronous scrape. Body: { "url", "extractors", "waitFor", "fullHtml", "screenshot" }
POST
/api/scrape/async Async scrape. Returns a jobId — poll /api/jobs/:jobId for results.
POST
/api/scrape/batch Batch scrape up to 10 URLs. Body: { "urls": ["...", "..."] }
GET
/api/jobs/:jobId Fetch the result of an async job.
GET
/api/jobs List all jobs.
GET
/api/health Service health check & uptime.
